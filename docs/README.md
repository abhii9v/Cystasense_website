# CystaSense - GitHub Pages

This directory contains the static website for GitHub Pages deployment.

## About

This is a static version of the CystaSense landing page. The full application is a Flask-based web application that requires a backend server to run.

## Full Application

To run the complete CystaSense application with all features including:
- User authentication
- Symptom tracking
- AI health assistant
- Community forum
- Database integration

Please refer to the [main README](../README.md) for setup instructions.

## Deployment

This site is automatically deployed to GitHub Pages via GitHub Actions when changes are pushed to the repository.
